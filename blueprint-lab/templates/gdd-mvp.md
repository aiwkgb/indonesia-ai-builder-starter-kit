## 5. Core fantasy

What feeling should the player get?

Example: "I am slowly building a peaceful Nusantara garden."

## 6. Core loop

Write the repeated loop.

```text
Do action → get reward → upgrade/unlock → repeat with a small variation
```

Example:

```text
Plant crop → wait → harvest → sell → buy upgrade → unlock new crop
```

## 8. Out of scope

Do not build these yet:

- Multiplayer
- Cloud save
- Ads/IAP
- 50+ levels
- Complex story
- Complex economy
- Account login
- Leaderboard

## 11. Recommended toolchain

- Beginner 2D: Godot
- Larger ecosystem: Unity
- Pixel art: Pixelorama or Aseprite
- Planning/writing: Claude or ChatGPT
- Code help: Cursor, Codex, Claude Code
- Early playtest: itch.io or local APK

## 12. Production roadmap

### Week 1 — Concept and core loop

Write this GDD and create a paper or simple prototype.

### Week 2 — Playable loop

Build one scene with the main interaction.

### Week 3 — Progression

Add simple reward, upgrade, and local save.

### Week 4 — Polish and playtest

Add UI polish, test with friends, write feedback notes.

## 13. Monetization notes

Do not add monetization before the game is fun.

Possible later paths:

- free demo,
- paid small game,
- rewarded ads,
- cosmetic IAP,
- supporter edition.

## 14. Playtest checklist

- Can a new player understand what to do in 30 seconds?
- Is the core loop playable without explanation?
- Is there one satisfying reward?
- Does the prototype run without critical bugs?
- Is the next improvement obvious?
