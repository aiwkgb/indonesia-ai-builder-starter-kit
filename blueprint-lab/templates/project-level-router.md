# Project Level Router Template

Use this before creating a PRD, GDD, investor deck, or AI coding prompt.

## 1. Raw idea

Write the idea in 1-3 sentences.

```text
Example: I want to build an app that helps small laundry businesses track orders and customer follow-ups.
```

## 2. Project type

Choose one:

- Software / web app
- Mobile app
- AI tool
- Dashboard / internal tool
- Automation
- Marketplace
- Game
- Public template / open-source project
- Service business
- Other: `<write here>`

## 3. Project seriousness level

Choose the lowest useful level.

| Level | When to choose it |
| --- | --- |
| L0 Idea Capture | You only want to save the idea |
| L1 Simple Experiment | You can test it in 1-3 days |
| L2 MVP | You want a usable prototype |
| L3 Monetizable Product | You want to sell or validate it with users |
| L4 Public Proof / Grant Ready | You need portfolio, free credits, grant, or investor trust |
| L5 Company Initiative | This is part of a long-term company operating system |

## 4. Why this matters

- Who is this for?
- What pain does it solve?
- Why now?
- Is this for learning, portfolio, money, client work, or public proof?
