# SAKA Blueprint Lab Lite

> Turn a raw idea into a simple build plan before asking AI tools to code.

SAKA Blueprint Lab Lite is a beginner-friendly planning layer for non-technical founders, vibe coders, solo operators, and first-time indie builders.

It helps you decide:

- what kind of project you are actually building,
- how serious the project is,
- which documents you need,
- what to build first,
- what to postpone,
- how to continue when you pause,
- how to ask AI coding tools more clearly.

## Ringkasan Bahasa Indonesia

SAKA Blueprint Lab Lite membantu founder non-teknis dan beginner builder mengubah ide mentah menjadi rencana project yang jelas sebelum masuk ke AI coding/no-code tools.

Tujuannya bukan membuat dokumen berat. Tujuannya adalah membuat kamu tidak mulai dari prompt yang kabur.

## Who this is for

- Non-technical founders with many ideas but no clear roadmap.
- Vibe coders who use AI coding tools but often get messy outputs.
- Solo operators who need small internal tools.
- Beginner indie game makers who only know the game vibe, not the production plan.
- Indonesian builders with limited budget who need a low-cost, template-first workflow.

## Start here

1. Use [`templates/project-level-router.md`](templates/project-level-router.md) to classify your idea.
2. If it is an app/software project, use [`templates/prd-lite.md`](templates/prd-lite.md).
3. If it is a game project, use [`templates/gdd-mvp.md`](templates/gdd-mvp.md).
4. Use [`templates/ai-prompt-pack.md`](templates/ai-prompt-pack.md) before asking AI tools to build.
5. Use [`templates/resume-brief.md`](templates/resume-brief.md) when you pause, so you can continue later.

## Project levels

| Level | Use when | Output |
| --- | --- | --- |
| L0 Idea Capture | You only have a raw idea | Short idea note and next question |
| L1 Simple Experiment | You want to test in 1-3 days | Mini brief, done criteria, next actions |
| L2 MVP | You want a usable prototype | PRD/GDD, roadmap, prompt pack, QA checklist |
| L3 Monetizable Product | You want to sell or validate with users | Offer, pricing hypothesis, launch plan |
| L4 Public Proof / Grant Ready | You want portfolio, credits, grant, or investor attention | Demo plan, public proof map, impact narrative |
| L5 Company Initiative | You are building a long-term company system | Operating model, repo strategy, standards |

## Safety note

Do not put private data into public examples.

Use fictional names, placeholder contacts, demo metrics, and sanitized screenshots only.

## Why this matters

AI coding tools are powerful, but unclear ideas still create unclear software.

Blueprint first. Build second.
