# Public Demo Script

Use this as a recording guide for a short public demo of SAKA Blueprint Lab Lite.

The video is still TODO. This file is only the script and publishing draft.

## Privacy rule

Record only public GitHub pages from this repository. Do not show private chats, local folders, dashboards, credentials, client data, family data, finance data, legal data, or fake metrics.

## 60-second video script

### 0-5 seconds — opening

Many people open an AI coding tool with a prompt that is too vague: "make me an app" or "make me a game".

This repo adds one step before coding: turn the idea into a small build plan.

### 5-15 seconds — show the router

Open `blueprint-lab/templates/project-level-router.md`.

Say:

```text
First, I classify the idea. Is this just an experiment, an MVP, or something that needs a more serious plan?
```

Use the fictional service business app idea.

### 15-30 seconds — show PRD Lite

Open `blueprint-lab/templates/prd-lite.md`.

Say:

```text
For a small app, I do not need a huge product document. I need the user, the problem, the MVP scope, the screens, and the data model.
```

### 30-42 seconds — show the example

Open `blueprint-lab/examples/simple-app-blueprint.md`.

Say:

```text
The example uses fictional data, so a beginner can copy the structure without exposing real customer or business information.
```

### 42-52 seconds — show the prompt pack

Open `blueprint-lab/templates/ai-prompt-pack.md`.

Say:

```text
Then I turn the plan into staged prompts. I do not ask AI to build everything at once.
```

### 52-60 seconds — close

Open `blueprint-lab/templates/resume-brief.md`.

Say:

```text
The last step is a resume brief. If I stop today, I know exactly what was done, what is next, and what not to build yet.
```

End with:

```text
Blueprint first. Build second.
```

## Short post draft

Use this only as a draft. Review before publishing.

```text
I made a small open-source workflow for beginner AI builders in Indonesia.

The problem is simple: many people start with a vague prompt like "make me an app".

SAKA Blueprint Lab Lite adds a planning step before coding:
- classify the idea,
- choose a small PRD or game design doc,
- cut the scope,
- turn the plan into staged AI prompts,
- save a resume brief so the project can continue later.

It is early, but the repo now has templates, examples, screenshots, release notes, and a public proof checklist.

Repo: https://github.com/aiwkgb/indonesia-ai-builder-starter-kit
```
