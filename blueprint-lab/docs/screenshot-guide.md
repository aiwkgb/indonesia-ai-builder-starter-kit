# Screenshot and Public Demo Guide

Use this before adding screenshots, GIFs, or walkthrough images to this repo.

## Safe screenshot rules

Only show:

- fictional demo ideas,
- public template files,
- generated example markdown,
- public repo pages,
- terminal output with no private paths beyond repo names,
- no secrets, tokens, or credentials.

Do not show:

- private SAKA OS data,
- real client/customer names,
- phone numbers,
- emails,
- finance/legal/family data,
- chat history,
- API keys or `.env` files,
- private dashboard screenshots.

## Recommended screenshots

1. `blueprint-lab/README.md` open on GitHub.
2. Project Level Router template.
3. PRD Lite template.
4. MVP GDD template.
5. Simple app example.
6. Mobile game example.

## Manual checklist before publishing

- [ ] No private data visible.
- [ ] No local credential file visible.
- [ ] No `.env` or token-like string visible.
- [ ] No real contact details visible.
- [ ] Screenshot uses demo idea only.
- [ ] Screenshot supports the repo narrative.

If unsure, do not publish the screenshot.
