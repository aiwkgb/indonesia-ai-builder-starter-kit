# Contributor Starter Path

This page is for first-time contributors who want to help without taking on a large task.

The best first contribution here is usually a small documentation improvement. One clear sentence, one better example, or one fixed link can help a beginner more than a big rewrite.

## What to work on first

Choose one of these:

- clarify one confusing sentence,
- add one missing explanation,
- fix one broken or unclear link,
- improve one checklist item,
- add one small public-safe example,
- suggest one new beginner template.

If the task feels bigger than one or two files, open an issue first.

## Good first issue checklist

Before opening or picking an issue, check:

- [ ] The task is useful for beginners.
- [ ] The task is small enough for one focused pull request.
- [ ] The task uses public-safe or fictional examples only.
- [ ] The task avoids unsupported claims about users, revenue, downloads, stars, or adoption.
- [ ] The task has a clear file or section to edit.

## How to open a helpful issue

Use one of the issue templates:

- Good first issue: for a small scoped task.
- Documentation improvement: for unclear docs or wording.
- Template request: for a new guide or template idea.
- Example request: for a beginner-friendly example idea.
- Bug report: for broken links or incorrect instructions.

A useful issue usually includes:

```text
What should change:
Where it should change:
Why it helps beginners:
Suggested wording or example:
```

## How to keep a pull request reviewable

A good beginner pull request should:

- edit only the files needed,
- avoid unrelated cleanup,
- explain what changed,
- explain why it helps beginners,
- avoid private data,
- avoid hype or unsupported claims.

If you are unsure, make the pull request smaller.

## Public-safe examples

Use fictional examples such as:

```text
A small service business wants to track customers, orders, and follow-ups.
```

Avoid real client names, private phone numbers, private emails, financial data, legal data, credentials, screenshots from private dashboards, or chat history.
