# Learning Paths untuk Beginner Builder Indonesia

Dokumen ini membantu kamu memilih titik mulai yang sesuai dengan tujuanmu. Tidak perlu membaca semua isi repo sekaligus. Pilih satu jalur, baca materi awalnya, lalu lakukan satu aksi kecil.

Repo ini berisi dokumentasi, template, checklist, contoh project, dan workflow membangun project dengan bantuan AI.

## Cara memakai dokumen ini

1. Pilih jalur yang paling dekat dengan kondisimu.
2. Baca 1-3 file pertama yang disarankan.
3. Pakai template, checklist, atau contoh yang relevan.
4. Lakukan aksi kecil pertama sebelum pindah ke materi lain.

## Catatan untuk semua jalur

- Mulai dari perubahan kecil yang bisa selesai dalam satu sesi belajar.
- Simpan progress lewat GitHub agar perubahan mudah dilacak.
- Gunakan checklist sebelum menganggap project siap dibagikan.
- Hindari menambahkan klaim besar tanpa bukti, terutama tentang jumlah pengguna, adopsi, download, stars, atau dampak.
