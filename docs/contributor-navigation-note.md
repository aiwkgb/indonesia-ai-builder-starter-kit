# Contributor Navigation Note

This short note helps first-time contributors find a simple place to start.

> Bahasa Indonesia-first. English summary included for international contributors.

## Ringkasan Bahasa Indonesia

Kalau ini kontribusi pertamamu, mulai dari perubahan kecil yang mudah direview.

Contoh kontribusi sederhana:

- Memperbaiki wording yang kurang jelas
- Meningkatkan dokumentasi
- Mengusulkan template baru
- Menambahkan contoh beginner-friendly
- Memperbaiki atau menyederhanakan checklist

Tempat mulai:

1. Baca `README.md` untuk memahami tujuan project.
2. Baca `CONTRIBUTING.md` untuk alur kontribusi.
3. Lihat GitHub Issues untuk mencari task kecil.
4. Buka `docs/README.md` untuk memilih dokumentasi.
5. Gunakan `templates/` untuk memahami format brief atau PRD.
6. Lihat `examples/` untuk contoh project pemula.
7. Gunakan `checklists/` untuk review sebelum mengusulkan perubahan.

Jaga perubahan tetap kecil, fokus, dan mudah direview.

## English summary

If this is your first contribution, start with a small reviewable change.

Simple contribution paths include:

- Fixing unclear wording
- Improving docs
- Suggesting templates
- Adding beginner examples
- Improving checklists

Places to start:

1. Read `README.md` to understand the project.
2. Read `CONTRIBUTING.md` for the contribution flow.
3. Check GitHub Issues for small tasks.
4. Open `docs/README.md` to choose documentation.
5. Use `templates/` to understand brief or PRD formats.
6. Explore `examples/` for beginner project examples.
7. Use `checklists/` before proposing changes.

Keep changes small, focused, and easy to review.
