# Use This Repo in 10 Minutes

This guide is for a beginner who opens the repository and wants to know what to do first.

You do not need to read every file. Pick one small idea, choose the right template, and leave with a clear next action.

## Before you start

Use a fictional or public-safe idea first. Do not paste real client data, private customer details, finance data, legal documents, credentials, or private chat history into a public repo or AI prompt.

## Minute 0-1 — choose one idea

Write one sentence:

```text
I want to build a simple tool for <user> to <main action> so they can <result>.
```

Example:

```text
I want to build a simple tool for a small service business to track customers, orders, and follow-ups.
```

Keep it small. One user, one main action, one result.

## Minute 1-3 — route the project

Open the Project Level Router:

- [`../blueprint-lab/templates/project-level-router.md`](../blueprint-lab/templates/project-level-router.md)

Decide whether your idea is:

- L0: just an idea,
- L1: a small experiment,
- L2: an MVP,
- L3 or above: too serious for a quick first build.

If you are unsure, choose L1 or L2. Do not start with a big company system.

## Minute 3-5 — choose the template

For a small app or dashboard, open:

- [`../blueprint-lab/templates/prd-lite.md`](../blueprint-lab/templates/prd-lite.md)

For a small game, open:

- [`../blueprint-lab/templates/gdd-mvp.md`](../blueprint-lab/templates/gdd-mvp.md)

For a landing page, open:

- [`../templates/landing-page-brief.md`](../templates/landing-page-brief.md)

Fill only the parts you understand. Leave the rest as questions.

## Minute 5-7 — compare with an example

Use one public-safe example:

- [`../blueprint-lab/examples/simple-app-blueprint.md`](../blueprint-lab/examples/simple-app-blueprint.md)
- [`../blueprint-lab/examples/mobile-game-blueprint.md`](../blueprint-lab/examples/mobile-game-blueprint.md)
- [`../examples/beginner-project-structure/README.md`](../examples/beginner-project-structure/README.md)

Do not copy the example blindly. Copy the structure, then replace the idea with your own.

## Minute 7-9 — turn the plan into AI prompts

Open:

- [`../blueprint-lab/templates/ai-prompt-pack.md`](../blueprint-lab/templates/ai-prompt-pack.md)

Start with a planning or scope prompt. Do not ask AI to build the entire app in one message.

A safer first prompt:

```text
Review this PRD Lite. Cut the MVP scope to the smallest useful first version. Do not add new features. List only the first 3 build steps.
```

## Minute 9-10 — save the next step

Open:

- [`../blueprint-lab/templates/resume-brief.md`](../blueprint-lab/templates/resume-brief.md)

Write:

```text
Last done:
Next action:
Blocked by:
Do not do yet:
```

This is the part that keeps the project from becoming messy after a break.

## What you should have after 10 minutes

You should have:

- one clear idea,
- one project level,
- one selected template,
- one small scope,
- one safe AI prompt,
- one next action.

That is enough for a first pass.

## What not to do yet

Do not start with:

- payment systems,
- full automation,
- real customer data,
- complex dashboards,
- a native mobile app,
- a huge prompt asking AI to build everything.

Start smaller than you want. You can always add more later.
