# v0.3.0 Release Notes

v0.3.0 has been released as a documentation-focused update.

## Summary

v0.3.0 focuses on beginner-facing documentation improvements for Indonesian AI builders and first-time contributors.

This release covers improvements to contributor guidance, issue templates, roadmap navigation, checklists, starter templates, beginner examples, and release readiness notes.

## What changed

- Improved contributor guide wording for first-time contributors.
- Improved issue templates so beginner contributors have clearer placeholders and examples.
- Improved contributor navigation notes to point contributors toward docs, templates, examples, checklists, and issues.
- Improved README and roadmap navigation for v0.3.0 planning.
- Improved beginner checklist clarity and flow.
- Improved starter template consistency and short helper guidance.
- Improved beginner example documentation with clearer audience, timing, and next steps.
- Added a v0.3.0 release readiness checklist.

## For beginner builders

The documentation now gives clearer paths for:

- Starting from a small project idea.
- Using templates before asking AI to make changes.
- Reviewing AI-assisted work before commit or deploy.
- Understanding when to use examples, checklists, and prompt packs.
- Keeping beginner projects small, practical, and reviewable.

## For contributors

The contributor-facing docs and issue templates now give clearer guidance for:

- First-time contribution paths.
- Small documentation improvements.
- Template and example suggestions.
- Beginner-friendly issue descriptions.
- Keeping pull requests focused and easy to review.

## Post-release notes

- v0.3.0 is a documentation-focused release.
- The release notes avoid claims about adoption, user count, stars, downloads, or large impact.
- Future work can continue through GitHub Issues, commits, changelog entries, and later releases.
