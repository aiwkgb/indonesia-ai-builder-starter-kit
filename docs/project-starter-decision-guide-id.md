# Project Starter Decision Guide

Guide ini membantu beginner AI builder Indonesia memilih file pertama yang perlu dibuka berdasarkan tujuan project.

Kamu tidak perlu memahami semua isi repo sebelum mulai. Pilih kebutuhan yang paling dekat, buka file yang disarankan, lalu lakukan satu langkah kecil.

## Cara pakai guide ini

1. Tentukan tujuan project kamu.
2. Buka file pertama yang paling relevan.
3. Pakai template atau checklist yang disarankan.
4. Isi brief dengan bahasa sederhana.
5. Gunakan Claude atau Codex untuk membantu merapikan ide, struktur, atau instruksi.
6. Review hasilnya, lalu commit perubahan kecil ke GitHub.

## Workflow sederhana

1. Pilih goal project.
2. Baca guide atau contoh yang relevan.
3. Copy template yang paling dekat dengan kebutuhanmu.
4. Isi brief dengan versi sederhana dulu.
5. Gunakan Claude atau Codex untuk membantu menyusun, merapikan, atau mengecek.
6. Review hasilnya dengan checklist.
7. Commit perubahan kecil ke GitHub.

## Kesalahan umum

- Membuka terlalu banyak file sebelum tahu tujuan project.
- Langsung meminta AI membuat semua hal tanpa brief yang jelas.
- Memakai PRD besar untuk ide yang masih sangat awal.
- Melewati checklist review sebelum membagikan hasil.
- Menambahkan klaim besar tanpa bukti tentang metrik, adopsi, atau dampak project.
