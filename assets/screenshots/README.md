## Privacy rules

Before capturing any screenshot:

- Only show public repo pages, fictional demo ideas, or generated example markdown.
- Do not show private chat history, real client names, real emails, real phone numbers, API keys, tokens, `.env` files, private dashboards, or any local file path beyond the repo path.
- If you are unsure whether something is safe to show, do not capture it.

Full rules: [blueprint-lab/docs/screenshot-guide.md](../../blueprint-lab/docs/screenshot-guide.md)

## How to add a screenshot

1. Open the target file on GitHub (not in a local editor) so no local paths appear.
2. Capture the screenshot following the privacy rules above.
3. Save it to this folder using the exact filename from the table.
4. Run the pre-publish checklist in the screenshot guide.
5. Update the Status column in this README from `TODO` to `Done`.

## File naming convention

Use lowercase, hyphen-separated names with a `.png` extension.

Example: `blueprint-lab-readme.png`
