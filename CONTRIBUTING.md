# Contributing Guide

Thank you for considering a contribution to Indonesia AI Builder Starter Kit.

This project exists to help Indonesian beginners build practical AI-assisted software projects using modern tools such as Claude, Codex, GitHub, and Vercel.

Catatan: project ini Indonesian-first. Kontribusi dalam Bahasa Indonesia sangat diterima, terutama jika membantu pemula memahami langkah berikutnya dengan lebih jelas.

## Welcome, first-time contributors

If this is your first open-source contribution, you are welcome here.

You do not need to start with a big feature. Small documentation fixes, clearer examples, and simple checklist improvements are valuable because this project is made to help Indonesian beginners learn step by step.

## First-time contributor path

If this is your first contribution, read the [`Contributor Starter Path`](docs/contributor-starter-path.md) first.

Start small:

1. Read [`README.md`](README.md)
2. Read [`docs/README.md`](docs/README.md)
3. Pick one small improvement from an issue or from a file you understand
4. Comment on the issue if you want to confirm the scope
5. Make a small focused change
6. Review your diff before committing
7. Open a pull request and explain what you changed
8. Wait for review and adjust if needed

## Good first contributions

If you want to suggest a small task, use the `Good first issue` template in GitHub Issues.

Helpful first contributions include:

- Fixing typos
- Fixing unclear instructions
- Improving unclear wording
- Improving beginner explanations
- Adding simple examples
- Adding or improving checklists
- Improving bilingual summaries
- Suggesting new templates

## Simple contribution workflow

For beginner contributors, use this workflow:

1. Choose one issue or one small documentation problem.
2. Make sure the change has a clear scope.
3. Edit only the files needed for that scope.
4. Keep the change small, focused, and reviewable.
5. Run a quick self-review before opening a pull request.
6. In the pull request, explain what changed and why it helps beginners.

Small pull requests are easier to review and easier to improve. If an idea feels too large, split it into smaller issues or smaller pull requests.

## Contribution principles

Please keep contributions:

1. Beginner-friendly
2. Practical and execution-oriented
3. Relevant to Indonesian creators, students, solo founders, or small businesses
4. Clear enough for someone with limited coding experience
5. Honest and non-hype

## What to avoid

Please avoid:

- Big rewrites without discussion
- Unsupported claims
- Claims about many users, stars, downloads, wide adoption, or large impact unless there is clear evidence
- Too much jargon
- Overengineering
- Promotional content

## Factual claims and tone

Keep documentation honest, practical, and beginner-friendly.

It is safe to say that this public repository is made to help Indonesian beginners and contains templates, docs, checklists, examples, and AI-assisted building workflows. It is also safe to describe progress through GitHub Issues, commits, changelog entries, and releases.

Do not make the project sound bigger than it is. Avoid unsupported hype, adoption claims, or promises of guaranteed results.

## Suggested template for new resources

When adding a new template or guide, include:

- Who this is for
- When to use it
- Step-by-step instructions
- Example output
- Common mistakes
- Next steps

## How to contribute

1. Fork this repository
2. Create a new branch
3. Make your changes
4. Open a pull request
5. Explain what you changed and why

## Code of conduct

Be respectful. This project is for learning, collaboration, and helping beginners grow.
